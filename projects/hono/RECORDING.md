# Record Hono documentation

This package contains the real [honojs/website](https://github.com/honojs/website) site at revision `2dd2952ea79dd1c622c9ba7df5a794201ea0e7ac`, with 91 page source files and its supporting code/content. Source files are preserved byte-for-byte; the added workspace and recording notes configure Code Replay. See UPSTREAM.json and LICENSE for provenance and rights. Upstream example projects, CI and agent instruction directories are omitted.

Tell your coding assistant: “Use Code Replay to record the hono project.” It can use the tool's `npm run record -- hono` command. The default target is `worker.ts`; choose any other real file if preferred. The complete site source remains in the Explorer while the selected file is replayed.

Open `Code Replay.code-workspace` to browse/customize the project in VS Code. Run Code Replay from its own directory; recording requires no site dependencies, server, account or deployment. It records one selected source file at a time, not the running website.

Building the site separately is optional and unvalidated here; follow the original upstream README for that workflow. Upstream branding identifies the original project and does not imply its endorsement of Averlo.
